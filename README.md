# Unity1WeekGameJam 黒いものは塗りつぶせ!
2026年7月26日~8月2日にUnityroomにて開催されたゲームジャムに向けた作品です。
ゲームジャムのお題は「しろ」でした。

## ゲームの概要
あなたは様々な黒い物体をクリックすると、背景の色に塗りつぶして白にすることができます。様々な障壁を塗りつぶして先に進み、ゴールとなる旗を目指しましょう。

[タイトル] 黒いものは塗りつぶせ!
[ジャンル] アクション、パズル
[特徴] ドット絵/2D
[プレイ時間] 10分程度
[制作ソフト] Unity 2022.3.40f1

### 操作説明
キーボード/マウス操作を前提としています。
* A/Dキー : 左/右移動
* Spaceキー : ジャンプ
* クリック : 対象の塗りつぶし
* Rキー : 現在の画面のギミックのリセット
* Tabキー : 音量設定画面
